# Etapa 3 — experiencia digital, SEO y preparación de lanzamiento

## Objetivo

Dejar BOTICAS DEL DR JUAN preparada para crecer sin convertir la web institucional en una aplicación compleja. La prioridad es que una persona pueda entender qué hacer, encontrar una botica o pedir ayuda desde el celular con el menor número posible de decisiones.

## Principios de experiencia

- Diseño mobile-first y lectura cómoda.
- Acciones principales visibles y con objetivos concretos.
- WhatsApp como canal de baja fricción, manteniendo atención humana.
- Lenguaje sencillo y sin tecnicismos innecesarios.
- Navegación por tareas: cotizar, orientarse, encontrar botica y contactar.
- Movimiento reducido cuando el dispositivo lo solicita.
- Contenido sanitario separado de cualquier recomendación clínica personalizada.
- No duplicar precio o stock cuando la futura tienda sea la fuente comercial.

## Accesibilidad

La evolución del sitio toma WCAG 2.2 como referencia. Se priorizan foco visible, navegación por teclado, controles suficientemente grandes, contraste, jerarquía semántica, textos legibles, alternativas para imágenes y ausencia de interacciones que dependan exclusivamente de precisión táctil.

## Fotografías

Las fotografías reales se incorporarán progresivamente. Se conservarán los originales y se generarán versiones web optimizadas. No se publicarán imágenes identificables de personal o clientes sin autorización aplicable. Cada imagen informativa tendrá texto alternativo útil y dimensiones explícitas.

## SEO local

La web institucional mantendrá una marca y entidad empresarial consistentes. Las sedes deben usar datos verificados antes de ampliar marcado estructurado por local. Se priorizarán nombre, dirección, teléfono, horario y enlace de ubicación coherentes con las fuentes públicas de cada establecimiento.

## Integraciones futuras

La tienda, chatbot, asistente OTC, redes sociales y analítica permanecen desacoplados. Cada integración debe poder activarse o retirarse sin comprometer la página institucional ni el correo corporativo.

## Privacidad

No se instalará seguimiento publicitario por defecto. Cualquier analítica o pixel futuro debe revisarse junto con consentimiento, finalidad, proveedor y actualización de la información de privacidad.

## Dominio

El dominio `boticasimilares.com` quedó conectado a GitHub Pages con HTTPS activo. Se verificaron dominio raíz, `www` y continuidad del correo corporativo. La regla permanente es separar cambios de web de los registros de correo.

## Estado de cierre

Etapa 3 cerrada técnicamente con dominio propio activo, HTTPS habilitado, correo verificado y controles automáticos reforzados. Las fotografías reales, contenido comercial ampliado e integraciones externas continuarán como fases posteriores y solo se publicarán cuando sus fuentes y responsables estén validados.
