# Fotografías y medios — BOTICAS DEL DR JUAN

Esta carpeta queda reservada para incorporar fotografías reales sin rehacer la estructura de la web.

## Organización recomendada por local

Cada botica tendrá su propia carpeta lógica y hasta cuatro tipos principales de imagen:

- `fachada`: imagen principal del establecimiento;
- `panoramica`: vista general del interior;
- `atencion`: zona de atención al público;
- `equipo`: personal del establecimiento cuando exista autorización para publicar la imagen.

## Convención de nombres

Usar minúsculas, sin tildes y con guiones. Ejemplos:

- `comas-1-fachada.webp`
- `comas-1-panoramica.webp`
- `comas-1-atencion.webp`
- `comas-1-equipo.webp`

## Tratamiento de imágenes

- conservar los originales fuera de la web;
- crear copias optimizadas para publicación;
- preferir WebP para contenido visible;
- mantener una relación de aspecto consistente cuando sea posible;
- evitar publicar matrículas, documentos, pantallas con datos personales u otra información sensible visible en la foto;
- incluir texto alternativo descriptivo en cada imagen publicada;
- no publicar fotografías de personas sin contar con la autorización correspondiente.

## Uso previsto

Las fotografías podrán utilizarse en:

1. ficha ampliada de cada local;
2. portada o secciones institucionales;
3. servicios y acompañamiento;
4. campañas o piezas sociales futuras.

La web no debe descargar las fotografías de todos los locales al abrir la página. Se recomienda carga diferida (`loading=lazy`) y versiones de tamaño adecuado para celular.
