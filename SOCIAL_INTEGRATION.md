# Ruta de integración con redes sociales

La web de BOTICAS DEL DR JUAN queda preparada para conectar perfiles y campañas sociales sin mezclar credenciales ni lógica de terceros con el contenido principal.

## Canales previstos

- Facebook
- Instagram
- TikTok
- YouTube
- LinkedIn
- X
- Threads
- Canal de WhatsApp

Los perfiles se mantienen desactivados hasta disponer de las URLs oficiales verificadas.

## Comercio y campañas

La configuración contempla enlaces separados para Facebook/Instagram Shop, TikTok Shop y páginas de aterrizaje de campañas. La tienda online seguirá siendo el destino comercial principal cuando sea habilitada.

Los enlaces de campañas deberán permitir identificar el origen de la visita mediante parámetros de campaña, sin alterar la navegación normal de la web.

## Medición

Se han reservado campos para Meta Pixel, TikTok Pixel y Google Tag. Permanecen desactivados. Antes de instalar herramientas de seguimiento debe revisarse la política de privacidad, el consentimiento que corresponda y la configuración de cada proveedor.

Nunca deben almacenarse contraseñas, tokens, secretos de API ni credenciales de redes sociales en este archivo público.

## Principio de experiencia

Las redes sociales deben llevar al usuario a una acción sencilla: conocer BOTICAS DEL DR JUAN, encontrar una botica, conversar por WhatsApp, recibir acompañamiento o acceder a la tienda. La navegación no debe depender de que el cliente tenga una cuenta en una red social.
